# AI Powered Video Summarization for Surveillance

## Description

This project summarizes long CCTV videos into short highlight videos using TensorFlow and OpenCV.

## Features

- Motion Detection
- Person Detection
- Vehicle Detection
- Fire Detection
- Event Scoring
- Clip Extraction
- Timeline Generation
- Report Generation
- Streamlit Dashboard
- FastAPI Backend

## Technologies

- TensorFlow
- OpenCV
- MoviePy
- Streamlit
- FastAPI
